# BOK Body 6.7.21 — установка GAS

GitHub Pages уже обновлён. Эти три серверных изменения нужны для бонуса за три «Ничего» и быстрой пакетной выдачи.

## Важно
Сохраните резервную копию действующего Code.gs. Новый App ID VK 54907336 остаётся в действующем VKCabinet.gs; **не заменяйте VKCabinet.gs**.

1. Создайте новый файл `BOK_WheelNothingBonus.gs` в проекте GAS и вставьте содержимое соседнего файла [BOK_WheelNothingBonus.gs](./BOK_WheelNothingBonus.gs).
2. В действующем `Code.gs` замените существующие маршруты на следующие (не добавляйте дубликаты):
```javascript
if (action === 'achPrivate') return json_(bokPrivateWithNothingBonus_(body));
if (action === 'achSpin') return json_(bokSpinWithNothingBonus_(body));
```
3. Внутри блока `if (action.indexOf('admin') === 0)`, **после** `checkAdmin_(body)`, добавьте:
```javascript
if (action === 'adminAchWinBatch') return json_(bokAdminWinBatch_(body));
```
4. Запустите в редакторе `bokWheelNothingBonusReadOnlyCheck`. Это только чтение, не крутит колесо и не начисляет бонусы.
5. Повторите `bokCodeRoutesReadOnlyCheck` — все семь прежних функций должны оставаться true, VK App ID — `54907336`.
6. Опубликуйте **новую версию существующего развёртывания** GAS. Адрес `/exec` изменять не требуется.

## Правила
- Каждый третий выпавший «Ничего» даёт одно дополнительное вращение; учитывается суммарное число таких выигрышей конкретного игрока.
- Все три «Ничего» в завершённой тройке автоматически помечаются «ВЫДАН».
- Уникальные идентификаторы `nothing-bonus:<ключ>:<номер тройки>` исключают двойное начисление при повторном запросе.
- Исторические «Ничего» учитываются: значение `pendingBonusGroups` в диагностике показывает, сколько компенсаций может быть начислено при следующих вращениях.
- Данные и формулы не мигрируются, архивы и ачивки не пересчитываются.
- В админке можно отметить выданными до 100 призов за один запрос. Повторная выдача сохраняет прежнюю дату.

## Что не делать
Не запускайте настоящие тестовые вращения. Не выполняйте повторные миграции достижений и начислений. Не изменяйте отдельный `VKCabinet.gs`.
