# BOK Номерок v6.5 — исправление интерфейса

## Изменены только файлы сайта
- `assets/admin.js`: устранена ошибка `GROUPS is not defined` при открытии вкладки «Настройки». Все параметры из серверного `form` теперь отображаются в настройках.
- `assets/app.js`: мобильная шапка с единым блоком кнопок; открытие публичного кабинета нажатием на имя в «Балансах» и в списке участников.
- `assets/styles.css`: адаптивная навигация в три равные колонки, перенос длинных имён в таблице балансов, интерактивные строки участников.

## Установка
1. Сохраните резервные копии трёх файлов из рабочего репозитория.
2. Замените `assets/admin.js`, `assets/app.js`, `assets/styles.css` файлами из архива.
3. Дождитесь обновления GitHub Pages и перезагрузите страницу (при необходимости очистите кеш браузера).
4. **Google Apps Script не менять и повторно не развёртывать**: серверная часть в v6.5 не изменена.

## Проверить
- Вкладка «Настройки» открывается и показывает все параметры.
- На iPhone три кнопки шапки располагаются в один ряд одинаковой высоты.
- В «Балансах» длинное имя переносится, а нажатие открывает публичную карточку.
- В списке участников на главной нажатие на имя открывает публичную карточку.
- Поиск и бронирование работают как раньше.

## Ограничения
Переход в кабинет использует публичную базу балансов. Участник без записи в базе балансов не получит карточку. Полное сквозное браузерное тестирование на iOS не проводилось; проверен синтаксис JS и три теста заморозки.
