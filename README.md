# Номерок — бронирование (GitHub Pages + Google Таблица)

Лёгкий сервис бронирования номерков для прямого эфира. Без сервера и базы данных:

- **Сайт** (`index.html`, `admin.html`) лежит на GitHub Pages.
- **Серверная часть** — Google Apps Script (`apps-script/`), данные хранятся в вашей Google Таблице.
- **Платежи** вручную: участник бронирует → оплачивает по ссылке/QR → оставляет под вашим постом комментарий с номерками и скриншотом → вы подтверждаете в админке.

## Что умеет

| | |
|---|---|
| Сетка | Красивая адаптивная сетка номерков; число номерков задаётся в настройках |
| Участники | Ссылка на профиль ВК → **имя и фото** берутся из профиля (без токена — со страницы профиля). Список по алфавиту: справа от сетки на ПК, под сеткой на телефоне |
| Таймер | Часов на подтверждение (по умолчанию 6). **Тихие часы** (по умолчанию 00:00–09:00): ночью таймер не идёт |
| Лимит | Пока бронь не подтверждена — нельзя занимать номерки сверх лимита (по умолчанию 5). После подтверждения лимит освобождается |
| Перерыв | Заморозка бронирования: новые брони закрыты, **все таймеры останавливаются** и продолжаются после возобновления |
| Ручная бронь | Админ может забронировать номерки за участника (сразу подтверждённой или с таймером), заблокировать номерки |
| Оплата | Ссылка на оплату кнопкой и **QR-кодом**; номерки через запятую копируются в один клик для комментария под постом |
| Оплата без комиссии | При брони от N номерков (по умолчанию 4) рядом с QR и ссылкой показывается надпись и кнопка «ЗАПРОСИТЬ РЕКВИЗИТЫ». Порог, надпись, текст кнопки и ссылка задаются в админке |
| Надписи | Когда все места разобраны и подтверждены, поверх сетки крупно появляется надпись с вашим текстом («Все места забронированы. Прямой эфир проведем {date}»). Необязательная плашка «идёт подтверждение» над сеткой |
| Эфиры | Кнопка «Завершить эфир и начать новый»: брони уходят во вкладку-архив «Архив №187», сетка очищается, номер эфира увеличивается |
| Вход | На странице бронирования — кнопка «🔐 Админ», в админке — «← К бронированию» |
| Уведомления | Всплывашка + звук в админке, письмо на e-mail (пуш в почтовом приложении телефона) |
| Правки с телефона | Вся таблица редактируется руками: статусы броней (выпадающий список), настройки |

## Установка (≈ 20 минут)

### 1. Таблица и скрипт

1. Создайте Google Таблицу, например «Номерок — бронирование».
2. **Файл → Настройки** → часовой пояс = ваш (Москва).
3. **Расширения → Apps Script**. Вставьте содержимое файлов из папки `apps-script/`:
   - `Code.gs` — в существующий файл `Code.gs`;
   - `TimeLogic.gs` — создайте файл кнопкой «+» → «Скрипт», назовите `TimeLogic`;
   - (необязательно) `appsscript.json` — включите «Показывать файл манифеста» в настройках проекта и вставьте.
4. **Настройки проекта (шестерёнка) → Свойства скрипта → Добавить**:
   - `ADMIN_PASSWORD` — пароль админки, **12+ символов**, случайный;
   - `VK_TOKEN` — необязательно, см. ниже.
5. В редакторе выберите функцию `init` → **Выполнить**. Google попросит разрешения: «Дополнительно → Перейти на страницу (небезопасно)» — это ваш собственный скрипт. Появятся листы **Настройки**, **Брони**, **Журнал**.
6. Выполните `installTrigger` (включает проверку каждые 5 минут: истечение броней, напоминания, письма). Затем `selfCheck` — покажет, что ещё не настроено. После перезагрузки таблицы появится меню **Номерок** с теми же пунктами.
7. Откройте лист **Настройки** и заполните: номер и название эфира, дату, количество номерков, реквизиты, куда присылать скриншот, e-mail для уведомлений.

### 2. Веб-приложение

1. **Начать развёртывание → Новое развёртывание → Веб-приложение**.
2. «Выполнять от имени» — **Я**; «У кого есть доступ» — **Все**.
3. Скопируйте адрес, заканчивающийся на `/exec`.
4. Вставьте его в `config.js`: `API_URL: 'https://script.google.com/macros/s/…/exec'`.

> После **любого** изменения кода скрипта: **Развёртывание → Управление развёртываниями → ✏️ → Версия: новая → Развернуть**. Адрес `/exec` не изменится.

### 3. Сайт на GitHub Pages

1. Создайте репозиторий, загрузите файлы этой папки (кроме `tests/` при желании).
2. **Settings → Pages → Deploy from a branch → main / (root)**.
3. Сайт: `https://<логин>.github.io/<репозиторий>/`, админка: `…/admin.html`.
4. Впишите адрес админки в настройку «Ссылка на админку (для писем)».

Посмотреть вёрстку без настройки можно сразу: откройте `index.html` двойным кликом — пока `API_URL` пустой, работает **демо-режим** (данные не сохраняются; пароль админки в демо — `demo`).

### 4. Имя и фото из профиля ВК

Участник вставляет ссылку на свой профиль (`vk.com/id123`, `vk.com/ник`, `m.vk.com/…`, `profile.php?id=…`). Сервер определяет имя и фото в таком порядке:

1. **Если задан `VK_TOKEN`** — официальный API ВК (надёжнее всего).
2. **Без токена** — читается открытая страница профиля `vk.com/…` (затем `m.vk.com/…`): имя из `og:title`, фото из `og:image`.
3. **Если не получилось** — участник вводит имя вручную; в списке тогда буква в кружке вместо фото.

Результат запоминается на 6 часов, чтобы не нагружать ВК.

> **Важно.** ВК может не отдавать страницы профилей серверам Google (капча, вход, блокировка). Заранее проверить это нельзя — зависит от ВК и меняется со временем. Проверка за минуту: в редакторе Apps Script выберите функцию **`testVk`** (в ней можно заменить ссылку на любую свою), нажмите «Выполнить» и откройте «Журнал выполнения»: там видно статус ответа ВК, найденное имя и фото. Если ВК блокирует — получите `VK_TOKEN` (ниже), это решает вопрос полностью.

`VK_TOKEN`: создайте приложение на [dev.vk.com](https://dev.vk.com) и возьмите в его настройках «Сервисный ключ доступа» (интерфейс VK меняется), вставьте в свойство скрипта `VK_TOKEN`. С токеном один человек также не обойдёт лимит, зайдя по другой форме ссылки.

Ссылка не доказывает владение профилем — это защита от случайных ошибок, а не от подмены; окончательно бронь подтверждаете вы по скриншоту.

## Как это работает

**Бронь.** Участник выбирает номерки, вставляет ссылку на ВК → видит свои номерки (с кнопкой «Копировать»), кнопку и QR-код оплаты и ссылку на ваш пост. Оплачивает, оставляет под постом комментарий с номерками через запятую и скриншотом оплаты, нажимает «Я оставил(а) комментарий» — бронь получает статус «ОПЛАТА ЗАЯВЛЕНА», вам приходит сигнал. Код брони участникам не показывается (он нужен только внутри таблицы).

Ссылка на оплату и ссылка на пост задаются в настройках («Ссылка на оплату», «Ссылка на пост для комментария»). По умолчанию оплата — `https://spasibomir.ru/pay/33434`. QR-код строится автоматически по ссылке.

**Оплата без комиссии.** Если в брони не меньше N номерков (настройка «Оплата без комиссии: от скольки номерков», по умолчанию 4), под QR-кодом и ссылкой появляется надпись и кнопка запроса реквизитов. Ссылка, текст кнопки и надпись настраиваются в админке (вкладка «Настройки» → «Оплата без комиссии»); в надписи можно писать `{n}` — подставится порог. `0` или пустая ссылка выключают блок. QR-код и ссылка на оплату остаются всегда.

**Таймер.** Дедлайн = момент брони + N *активных* часов. Пример для окна 00:00–09:00:

| Бронь | 6 часов | Дедлайн |
|---|---|---|
| 14:00 | | 20:00 |
| 22:00 | 2 ч до полуночи + 4 ч с 09:00 | 13:00 следующего дня |
| 03:00 | отсчёт с 09:00 | 15:00 |

Окно может переходить через полночь (23:00–08:00) или быть выключено.

**Перерыв.** Нажмите «⏸ Перерыв» в шапке админки (или поставьте «ДА» в настройке прямо в таблице). Таймеры замораживаются, остаток запоминается; при возобновлении дедлайны пересчитываются от момента возобновления.

**Надпись «все места забронированы».** Показывается, когда свободных номерков нет и ни одна бронь не ждёт подтверждения (заблокированные номерки считаются занятыми). Текст и выключатель — в «Настройки → Надписи на странице бронирования». В тексте работают подстановки `{date}` (поле «Дата и время эфира», например «в 15:00 28.10.2026») и `{number}` (номер эфира); первое предложение выводится крупно, остальное — подписью. Если отменить бронь, надпись исчезнет сама (до ~15 секунд). Отдельный необязательный текст «идёт подтверждение» показывается плашкой над сеткой, когда места разобраны, но часть броней ещё не подтверждена.

**Завершение эфира.** «Настройки → Завершить эфир и начать новый»: брони текущего эфира копируются в новую вкладку «Архив №187» (в таблице), рабочий лист «Брони» очищается, номер эфира увеличивается на 1 (или вы вводите свой), дата сбрасывается. Блокировки номерков не переносятся. Если есть неподтверждённые брони, нужно явно подтвердить их закрытие: в архиве они будут со статусом «ИСТЕКЛА». Данные очищаются только после проверки, что архив записан полностью. В колонке «Эфир» у каждой брони хранится номер эфира.

**Просроченная бронь** получает статус «ИСТЕКЛА», номерки освобождаются. Если человек всё же оплатил — «♻ Восстановить» в админке (если номерки ещё свободны).

**Правки в таблице руками** (лист «Брони»): меняйте статус выпадающим списком. Изменение видно на сайте в пределах ~15 секунд.

### Статусы

`ОЖИДАЕТ` → `ОПЛАТА ЗАЯВЛЕНА` → `ПОДТВЕРЖДЕНА`; `ИСТЕКЛА`, `ОТМЕНЕНА`; `БЛОК` — номерок закрыт вами.

## Ограничения (честно)

- **Ссылка на ВК не доказывает владение профилем.** Кто-то может указать чужую ссылку. Защита — ручное подтверждение по скриншоту и то, что вы видите ссылку в админке.
- **Скриншоты на сайт не загружаются** (бесплатно негде хранить файлы) — участники прикладывают их к комментарию под вашим постом.
- **Фото из ВК** показываются прямой ссылкой на сервер ВК. Если ссылка перестанет открываться, вместо фото будет буква в кружке.
- **Нагрузка.** Apps Script обрабатывает ограниченное число одновременных запросов, а каждая бронь занимает 1–3 секунды. Для десятков участников в минуту нормально; если ожидается *шквал* в первую минуту после объявления, часть людей может получить «Сервер занят, повторите» — актуальные квоты смотрите в документации Google. Если упрётесь — перенос на VPS с базой данных: данные из листа «Брони» переносятся один к одному.
- **Почта.** У Google есть дневной лимит писем; поэтому события склеиваются в одно письмо не чаще раза в 2 минуты.
- **Часовой пояс** задаётся смещением от UTC; переход на летнее время не учитывается (для Москвы не нужен).
- Лимит запросов по клиенту (`clientId`) — «мягкая» защита от случайных повторов, а не от целенаправленной атаки. Пароль админки проверяется с задержкой на каждую неудачную попытку — делайте его длинным.
- Реквизиты и инструкция из настроек видны любому, кто откроет адрес API, — как и тем, кто сделает бронь. Не пишите туда ничего лишнего.
- Репозиторий публичный: в нём нет секретов (пароль и ключ VK лежат только в свойствах скрипта), но адрес `/exec` виден всем — так и должно быть.

## Если что-то не работает

| Симптом | Что проверить |
|---|---|
| На сайте «Нет связи с сервером» | В `config.js` адрес именно с `/exec`; в развёртывании доступ «Все»; после правок кода сделана **новая версия** развёртывания |
| Админка: «Неверный пароль» | Свойство `ADMIN_PASSWORD` в настройках проекта (не в таблице!), без пробелов по краям |
| Нет писем | Заполнен e-mail в «Настройках»; в Apps Script разрешена отправка почты (при первом запуске `selfCheck`/`init` нужно принять разрешения); смотрите папку «Спам» |
| Брони не истекают сами | Выполнен `installTrigger`; в Apps Script → «Триггеры» виден `tick` |
| Тихие часы «сдвинуты» | Проверьте «Часовой пояс организатора» и формат времени `ЧЧ:ММ` (ячейки настроек — текстовые) |
| Ошибка «Нет листа…» | Выполните `init` |
| Вместо имени просит ввести вручную | ВК не отдал страницу профиля — запустите `testVk` (см. раздел про ВК) или задайте `VK_TOKEN` |
| После обновления кода нет новых настроек | Меню «Номерок» → «1. Создать листы / обновить настройки», затем новая версия развёртывания |

## Проверка после установки (10–15 минут)

1. Открыть сайт: видны номер и название эфира, сетка нужного размера.
2. Выбрать 2 номерка → «Забронировать» → вставить ссылку ВК → получить код, дедлайн и реквизиты.
3. В таблице на листе «Брони» появилась строка со статусом `ОЖИДАЕТ`; на сайте номерки жёлтые, имя в списке справа/снизу.
4. Нажать «Я отправил(а) скриншот» → в админке всплыло уведомление и прозвучал сигнал, на почту пришло письмо.
5. В админке «✅ Подтвердить» → номерки стали серыми, в списке имя без пунктирных рамок.
6. Взять ещё 5+ номерков до подтверждения → отказ по лимиту; после подтверждения брать можно снова.
7. Включить перерыв → на сайте баннер, бронь невозможна; выключить → таймеры продолжились.
8. Ручная бронь и блокировка номерка в админке (вкладка «Сетка»).
9. Поменять количество номерков и название эфира в настройках → обновилось на сайте.
10. Открыть сайт и админку с телефона.

## Разработка

```bash
npm test      # серверная логика, разбор страниц ВК и интерфейс (88 тестов), без зависимостей (Node 18+)
```

Серверная логика прогоняется в Node с имитацией сервисов Google (`tests/harness.js`), поэтому время/лимиты/перерыв проверяются автоматически. Интерфейс в тестах — в демо-режиме на минимальном фейковом DOM, это не заменяет проверку в реальном браузере.

Сторонний код: `assets/qrcode.js` — библиотека qrcode-generator (MIT, © Kazuhiko Arase), лицензия в шапке файла.

Структура: `index.html` + `assets/app.js` — страница участников; `admin.html` + `assets/admin.js` — админка; `assets/common.js` — общие функции и демо-бэкенд; `apps-script/` — сервер.
