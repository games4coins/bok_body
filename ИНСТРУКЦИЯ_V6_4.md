# BOK Номерок v6.4 — тестовое обновление

## Состав обновления
- Админка «Подарки»: участники сгруппированы по имени; в заголовке показаны количество ожидающих и полученных подарков. Раскрытие показывает отдельные записи и позволяет отметить выдачу.
- Каталог подарков: отдельный лист `Каталог подарков`, создаётся автоматически с примерами. Администратор добавляет новые позиции, включает и отключает их; назначает подарок только из активного каталога.
- Поздравление победителя: графический фон `assets/winner-premium-bg.png`, динамические имя, номер, фотография и текст. Предпросмотр и экспорт PNG рисуются одним Canvas.

## Установка (сначала на тестовом экземпляре!)
1. Создайте копии Google Таблицы, Google Apps Script и сайта.
2. В тестовом Apps Script замените **целиком** `Players.gs` и `Code.gs` из `apps-script/`. Остальные `.gs` не меняйте. Сохраните и обновите тестовое веб-развёртывание (новая версия).
3. В тестовом GitHub Pages замените **целиком** `assets/admin.js` и `assets/styles.css`, добавьте новый файл `assets/winner-premium-bg.png`.
4. Убедитесь, что `config.js` указывает на тестовый `/exec`.
5. В админке откройте «Подарки»: создастся лист «Каталог подарков». Проверьте назначение, раскрытие списка, получение, отключение позиции каталога.
6. Откройте «Победитель», введите номер подтверждённой брони и сравните предпросмотр со скачанным PNG.

## Важные ограничения
- Изменения не вносились в рабочую таблицу или опубликованный сайт.
- Старые подарки остаются в листе «Подарки» без изменений; каталог управляет только новыми назначениями.
- Обмен подарков в этой версии НЕ реализован. Это отдельная механика, требующая правил, журнала и подтверждения администратора.
- Фотографии ВК иногда недоступны для Canvas из-за CORS. Тогда на открытке будет инициала имени; фон и текст сохранятся.
- Проверка синтаксиса выполнена; 3 теста заморозки пройдены. Полный старый набор тестов не прошёл без ошибок: в нём есть проверки прежней структуры интерфейса. Требуется ручная интеграционная проверка.
