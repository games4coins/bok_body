# BOK Номерок v6.1 — тестовая сборка

## Что изменилось
- Публичные балансы: фильтры по точному количеству пропусков (0–4) и заморозке.
- Публичный кабинет без авторизации: поиск участника по имени, только уже публичные сведения; запрос заморозки/разморозки ведёт в сообщения сообщества.
- Админка: вкладка «🎉 Победитель», поиск по подтверждённому номерку ТЕКУЩЕГО эфира, анимированный предпросмотр, сохранение квадратного PNG 1080×1080.
- Настройки: freezeMinDays, freezeMaxDays (1–90), winnerText с {name}, {number}, {event}.
- Сервер проверяет выбранные админом минимальный и максимальный сроки заморозки.

## Установка только на тестовую копию
1. Создайте копию рабочей Google Таблицы и Apps Script. Сохраните резервную копию.
2. В тестовом Apps Script замените Code.gs, Players.gs, TimeLogic.gs, getlink.gs, appsscript.json из apps-script/.
3. Проверьте SS_ID в свойствах тестового скрипта: он должен указывать только на копию таблицы.
4. Запустите init() на тестовой копии (он добавит новые настройки), затем опубликуйте новое развёртывание тестового веб-приложения.
5. Разместите файлы сайта на отдельном тестовом GitHub Pages, установите URL тестового API в config.js. НЕ используйте URL рабочего API для тестов.
6. В админке настройте минимальный/максимальный срок, текст поздравления; проверьте номерок с подтверждённой бронью.
7. Проверьте запрет бронирования для замороженного получателя, досрочную разморозку со штрафом, старые бессрочные заморозки, закрытие эфира и откат.

## Ограничения и безопасность
- Личный кабинет НЕ авторизует пользователя: нельзя показывать непубличные данные и менять баланс. Имя можно выбрать чужое.
- Бронирование за подругу сохраняется как раньше.
- Публичные балансы в режиме «скрыт» останутся скрытыми в кабинете.
- Фото ВК может запрещать кросс-доменное чтение canvas. Тогда PNG создаётся с буквой имени, а веб-предпросмотр показывает фото.
- Поздравление формируется только по подтверждённым номеркам текущего эфира. Это НЕ проведение розыгрыша и НЕ автоматическое закрытие эфира.
- PNG статичен; анимация конфетти работает в предпросмотре.
- Отправка сообщений ВК автоматом не производится.
- Если опубликованная версия сервера отличается от исходников, сначала синхронизируйте развёртывание.
