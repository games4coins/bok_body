# BOK Номерок v6.3 — исправления

## Исправления
- Поиск участника в кабинете: при смене участника поле ввода и подсказки снова доступны, поддерживаются ссылки vk.com/vk.ru и короткие идентификаторы.
- Фильтры пропусков: по умолчанию ❌2 и ❌3, ❌4 убран из интерфейсов балансов и списка игроков админки.
- Подарки: перед первой записью сервер создаёт лист «Подарки» с заголовками (раньше при отсутствии листа возникала внутренняя ошибка).
- Открытка победителя: переработано HTML/CSS-превью — крупный портрет, бордово-золотая палитра, премиальная типографика и декоративные элементы.

## Установка — только тестовая копия
1. Скопируйте текущую таблицу и проект Apps Script. Сохраните старый URL `/exec` и исходники.
2. В тестовом Apps Script замените `Players.gs` из папки `apps-script` и опубликуйте **новую версию** тестового веб-приложения. Проверьте правильность `SS_ID`.
3. На тестовом GitHub Pages замените `assets/app.js`, `assets/admin.js`, `assets/styles.css`.
4. Проверьте, что `config.js` тестового сайта ссылается на тестовый `/exec`.
5. Обновите браузер с очисткой кеша. Откройте кабинет → сменить участника → введите имя или ссылку.
6. Откройте админку → Подарки → выберите игрока из подсказок → добавьте тестовый подарок → отметьте полученным → проверьте кабинет.
7. Проверьте фильтры и открытку. Экспорт PNG выполняется отдельной canvas-отрисовкой и может отличаться от HTML-превью. Фотографии VK могут не экспортироваться из-за CORS.

**Важно:** ошибка «Внутренняя ошибка сервера» в подарках была исправлена для случая отсутствующего листа. Без журналов Apps Script нельзя гарантировать, что это единственная причина ошибки. Если ошибка останется, откройте Apps Script → Выполнения и передайте текст ошибки без токенов/паролей.

Не устанавливайте на рабочую таблицу до тестирования. Функции заморозки и обмена требуют регрессионной проверки.
